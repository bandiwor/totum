# Наборы (packs)

Приложение стартует пустым: нет категорий упражнений, типов пар, категорий денег и т.д.
Всё это приходит из **наборов** — встроенных (Настройки → Наборы) или вставленных как JSON
(например, сгенерированных ИИ). Перед применением показывается, что изменится в каждом
разделе: добавится / изменится / удалится. Разделы можно отключать. Перед применением
делается автокопия.

## Формат

```json
{
  "totum": "pack",
  "version": 1,
  "name": "Мой набор",
  "description": "Необязательное описание",
  "settings": { "theme": "dark", "accentHue": 25 },
  "docs": {
    "bells": { "slots": [] }
  },
  "collections": {
    "exerciseCategories": [
      { "id": "cat-chest", "name": "Грудь", "color": "c1", "order": 0 }
    ],
    "foods": { "mode": "replace", "items": [] }
  }
}
```

- `settings` — частичные настройки приложения (тема, акцент, язык, модули…).
- `docs` — частичные одиночные документы (`bells`, `trainingProgram`, `mealPlan`,
  `bodyProfile`, `money`). Поля сливаются поверх текущих.
- `collections` — по имени коллекции: массив элементов (режим `merge`) или
  `{ "mode": "merge" | "replace", "items": [...] }`. В режиме `replace` элементы, которых
  нет в наборе, удаляются.

### Сопоставление элементов

1. Совпал `id` с существующим → элемент **изменяется** (поля набора поверх текущих).
2. Иначе совпало `name` (или `title`) без учёта регистра → тоже изменение существующего;
   `id` из набора переназначается на найденный во всех ссылках набора.
3. Иначе элемент **добавляется**. Без `id` он получает случайный.

`createdAt`/`updatedAt` указывать не нужно. Ссылки между элементами — поля, оканчивающиеся
на `Id` (`categoryId`, `subjectId`, `foodId`…). Чтобы сослаться на элемент из того же набора,
дай ему свой `id` (любая уникальная строка, например `"sub-math"`).

Даты — `"YYYY-MM-DD"`, время — минуты от полуночи (`9:30` → `570`), цвета — `"c1"`…`"c8"`.

Полное описание полей каждой коллекции — кнопка «Формат для ИИ» в Настройках → Наборы
(источник: `src/core/packs/aiGuide.ts`).
